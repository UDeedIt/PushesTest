# Privacy Policy for Pushes Test

**Pushes Test** is built as a D2D (Developer-to-Developer) utility. This service is provided at no cost and is intended for use as is.

### 1. Data Collection and Use
**Pushes Test does not collect, store, or share any personal information.** 
- All notification data (Titles, Bodies, and Payloads) entered by the user stays strictly on the local device.
- The application does not use any third-party analytics, tracking, or advertising SDKs.
- No data is transmitted to external servers.

### 2. Permissions
The app requires the following permissions to function:
- **POST_NOTIFICATIONS:** To display the test notifications you create.
- **USE_FULL_SCREEN_INTENT:** To allow testing of high-priority alerts (Alarms/Calls).
- **VIBRATE:** To provide haptic feedback during testing.

### 3. Links to Other Sites
This service may contain links to external sites (e.g., Medium or support pages). If you click on a third-party link, you will be directed to that site. Note that these external sites are not operated by me.

### 4. Contact
If you have any questions or suggestions about this Privacy Policy, do not hesitate to contact me via the GitHub repository issues.
